# 國一國數闖關王（翰林版 七上 國文＋數學）

給威橙在 iPad 上用的學習遊戲，玩法和「國一闖關王」（社會＋自然）相同：每天要完成國文和數學兩科挑戰，內含講義的重點筆記。
不用上架，不用帳號，進度存在 iPad 本機（和其他闖關王分開存）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 畫面與樣式 |
| `app.js` | 遊戲邏輯；最上面是**任務與獎勵規則**（和其他闖關王同一套程式） |
| `chapters.js` | App 設定、課次、段考範圍、**重點筆記**（整理自「課文重點整理\威橙」的國文、數學講義） |
| `questions.js` | **題庫** 312 題：國文 186 題（含 61 題手寫生字）、數學 126 題 |
| `write.js` | **手寫生字題**：田字格手寫板與批改 |
| `dog.js` | **狗狗養成**（黑四目長毛臘腸） |
| `sw.js`、`manifest.webmanifest`、`icon-*.png` | 離線快取、主畫面圖示 |

## 題型
- 選擇題、是非題、排序題
- **手寫生字**：看注音，用手指或 Apple Pencil 在田字格寫出國字（課文中的字詞，例：山巒、蹣跚、心無旁騖）
- 數學以**觀念和題型**為主，計算都很簡單

## 手寫批改
- **自動辨識**（預設）：把筆畫線條座標送到 Google 手寫辨識，答案在前 10 個候選字內就算對；第一次沒過可以再寫一次，第二次還錯就算錯並顯示正確字。
- **自己對答案**：不連網，寫完把自己的字和正確答案並排，自己按對或錯。沒有網路時會自動改用這個。
- 家長頁可以切換。

## 範圍
- 第一次段考：L1～L3＋語文常識一、數學 1-1～1-4
- **第二次段考（預設）**：L4～L6＋語文常識二、數學 2-1～2-4
- 第三次段考：L7～L10、數學 3-1～3-3
- 家長頁可以一鍵切換，也能逐課勾選。實際範圍以學校公告為準。

## 每日任務與獎勵
和國一闖關王相同：國文挑戰、數學挑戰、讀一篇重點、複習錯題；兩個挑戰都完成才算打卡。每天最多 100 金幣；獎勵價格家長頁可改；孩子申請兌換 → 家長按「兌換」才扣金幣。

## 🐶 狗狗養成（dog.js）
- 預設是**黑四目長毛臘腸**「小臘腸」，首頁左上角點下去就是養成頁。
- 規則和小雞相同：照顧 20～50 金幣、每天免費摸摸頭 3 次、答對 1 題成長 +1、**每週成長上限 330**，目標 1/10 期末考前養成。
- 成長階段（體型、姿勢、毛量一階一階明顯不同）：新生小奶狗（趴在小被子上睡覺）→ 搖搖幼犬（大頭圓眼短腿）→ 活潑小臘腸（吐舌奔跑）→ 少年臘腸（身體拉長、耳尾毛變長）→ 帥氣大臘腸（抬頭挺胸、一身長毛）→ 傳說神犬（翅膀、光環、飛起來）。
- 商店：毛色 10 種、帽子 9 種、衣服 11 種（依身體形狀裁切）、嘴裡叼的東西 12 種、坐騎 9 種、背景 20 種（含台北 101、鵝鑾鼻燈塔、九份、倫敦大笨鐘、比薩斜塔、荷蘭風車、京都鳥居、泰姬瑪哈陵…）。

## 加入 iPad 主畫面
用 **Safari** 開啟網址 → 分享 ⬆️ →「加入主畫面」。家長密碼預設 **0000**。

## 新增題目
在 `questions.js` 照格式加。手寫題：`W('id', 課, '句子裡用（注音）標出要寫的字', '答案', '說明')`。
更新後把 `sw.js` 的 `VERSION` 改一下（例如 `g7cm-v2`），iPad 才會抓到新版。
